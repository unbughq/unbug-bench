# Working in this repository

Read `ARCHITECTURE.md` when changing module boundaries or factory execution.
Read `SPEC.md`, `PROTOCOL.md`, `V2.md` and `FACTORY.md` before changing scientific
rules; keep prompts and code consistent with those contracts.

Prefer deleting obsolete paths to adding recovery exceptions. Preserve existing
work in progress and qualified release pins. Use focused regression checks while
editing and the full offline suite before landing; report live-validation gaps.
Keep the architecture guide current. Put review findings in the PR, without
creating design/review dossiers or agent handoff logs in the source tree.
